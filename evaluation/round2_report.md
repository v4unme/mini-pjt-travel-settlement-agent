**개선폭 +8건의 구성** (공정한 비교를 위해 기준 변경과 Agent 개선을 나눠 기록한다)
- 판정 기준 수정만으로 +4건: round1 답변을 Agent 재실행 없이 수정된 기준으로 다시 채점하면 11/15. 불필요한 expected_tools 조건(`get_trip_expenses`) 제거, Judge 에 도구 결과 제공, 초과 금액 지표를 초과 금액 trait 로 한정한 효과다.
- Agent 개선으로 +4건 (11 → 15)
  1. 점검 근거 조항을 `check_settlement` 가 코드로 직접 첨부 → 규정 날조 4건 → 0건 (#3, #11)
  2. 예외 승인된 초과도 결재ID 와 함께 확인 사항에 표시 (#12)
  3. 동시 검색 시 규정 조항이 중복 저장되던 검색 버그 수정 → '예외 결재' 조항 검색 회복 (#5)
  4. 일부만 묻는 질문에도 점검 답변 형식 유지, 규정 질문은 반드시 검색 후 답변 (#3, #7)
- 채점 원칙 정리: 숫자(금액·날짜·건수·ID)는 정확 일치, 문장은 의미 판정(LLM-as-Judge + 사람 확인). 원칙 변경 후에도 15/15 를 유지했다.
